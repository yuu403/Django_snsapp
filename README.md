# Django SNS App

## 概要

Djangoを用いて開発したSNSアプリです。

ユーザー登録・ログイン機能をはじめ、投稿、コメント、いいね、フォロー機能を実装しています。

単に機能を実装するだけでなく、設計の改善やユーザーテストを通して保守性・拡張性・使いやすさを意識して開発しました。

## 工夫した点

### 1. Ajaxによる非同期いいね機能

いいね操作のたびにページ全体を再読み込みすると操作性が悪いため、Ajaxを利用してページ遷移なしでいいね処理を行えるようにしました。

---

### 2. フォロー機能の設計改善

開発初期はConnectionモデルを利用してフォロー関係を管理していました。

しかしコードの見通しが悪くなり、機能追加時の保守性にも課題があったため、Followモデルによる中間テーブル設計へ変更しました。

これにより、

* フォロー関係の管理が明確になる
* クエリの可読性が向上する
* 将来的な拡張がしやすくなる

というメリットを得られました。

---

### 3. JavaScriptの責務分離

開発初期はHTML内にJavaScriptを直接記述していました。

その後、保守性向上のためJavaScriptを外部ファイルへ分離し、

* HTML
* CSS
* JavaScript

それぞれの責務を明確化しました。

## ユーザーテストによる改善

ゼミ仲間3名に実際に利用してもらいフィードバックを収集しました。

### 指摘された課題

* 現在開いているページが分かりにくい
* ログアウトボタンが他の操作ボタンと近く誤操作しそう

### 改善内容

* ナビゲーションバーにアクティブ表示を追加
* ログアウトボタンの配置を見直し

この経験から、開発者視点だけでなくユーザー視点でUIを考える重要性を学びました。

---

## 開発中に発生した課題

### PostgreSQL運用

Renderの無料データベース利用時に期限切れや接続設定の問題が発生しました。

原因調査や設定修正を行う中で、

* 環境変数
* DATABASE_URL
* 本番環境設定

について理解を深めました。

---

### デプロイ時の依存関係管理

requirements.txtにローカル環境の不要なライブラリが含まれていたためデプロイに失敗しました。

必要なライブラリのみを整理し、本番環境向けの依存関係管理を行いました。
